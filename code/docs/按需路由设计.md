## 1. 决策契约：两个 opt-in 开关

| 开关 | 落点 | 默认值 | 语义 |
|---|---|---|---|
| `graph_recall_selective` | `settings.py:157` | `False` | 开启后，仅当 top1 高置信 **且** 召回充足才跳过图召回（省一次 DB 往返） |
| `wiki_nav_selective` | `settings.py:183` | `False` | 开启后，查询词元已很丰富时跳过导航扩展（省一次 50ms SELECT） |

## 2. 三个站位常量 + self_check 不变量

> 定义见 `config/decisions.py`；校验见 `decisions.self_check()`（`decisions.py:1026`）。

### 2.1 `GRAPH_SKIP_SCORE = 0.85`（`decisions.py:930`）

- **含义**：图召回路由跳过阈值。**仅当** `top1.final_score >= 0.85` **且** `len(retrieved) >= GRAPH_SKIP_MIN_CHUNKS` 同时成立时，才跳过图召回。
- **理由**：已通过 0.50 阈值闸门、且高置信 + 召回充足时，图扩展边际收益低，可省一次 DB 往返。区间 MUST 在 `(RELEVANCE_THRESHOLD_VECTOR, 1.0)` —— 低于主召回阈值会让本应拒答的请求误走图（`decisions.py:933-935`）。
- **self_check 不变量**（`decisions.py:1267-1268`）：`0.5 < GRAPH_SKIP_SCORE < 1.0`，否则 `RuntimeError`。

### 2.2 `GRAPH_SKIP_MIN_CHUNKS = 8`（`decisions.py:937`）

- **含义**：图召回路由的「召回充足」门槛。
- **理由**：`retrieved` 经 `TOP_K_RERANK=8` 截断后恒为 8，故该条件常态为真，**路由主判据实际是 `GRAPH_SKIP_SCORE`**（`decisions.py:940`）。
- **self_check 不变量**（`decisions.py:1269-1270`）：`GRAPH_SKIP_MIN_CHUNKS >= 1`，否则 `RuntimeError`。

### 2.3 `WIKI_NAV_SELECTIVE_MIN_TERMS = 3`（`decisions.py:131`）

- **含义**：wiki 导航路由门槛。开启后，仅当 `len(ilike_terms) >= 3` 才跳过导航扩词。
- **理由**：wiki 在第 4 步、主召回**之前**执行，`retrieved` 尚不存在，故用前置词元数信号；`len(ilike_terms)` 上限 = `ILIKE_MAX_TERMS=3`，故本值 = 3 即「词元已饱和，扩词边际收益低」（扩词边际收益低，省一次 50ms SELECT）。`decisions.py:136`、`143`。
- **self_check 不变量**（`decisions.py:1300-1301`）：`1 <= WIKI_NAV_SELECTIVE_MIN_TERMS <= ILIKE_MAX_TERMS`，否则 `RuntimeError`（超上限 = 永不跳过，空操作）。

> 注：`WIKI_NAV_SELECTIVE_MIN_TERMS` 的跨模块上限一致性（`<= ILIKE_MAX_TERMS`）改由单测 `tests/wiki/test_nav_constants.py` 钉住，**不进 self_check**（配置层不反向依赖服务层，`decisions.py:1287-1290`、`123`）。

## 3. 两个纯函数的真值表

> 实现见 `retrieve/__init__.py:45-68`。两函数均为**纯函数**：default-off 时恒 `True`，开启时只依赖入参，不读请求外的状态。返回值 `True` = 执行（调用 recall_by_graph / 执行 wiki 导航）；`False` = 跳过。

### 3.1 `_graph_should_recall(top1_score, retrieved_n)`（`retrieve/__init__.py:45-55`）

判定：`selective off → True`；`selective on → not(top1_score >= 0.85 and retrieved_n >= 8)`。

| `graph_recall_selective` | `top1_score` | `retrieved_n` | 返回值 | 动作 |
|---|---|---|---|---|
| False（默认） | 任意 | 任意 | **True** | 调用 `recall_by_graph`（与未引入路由一致） |
| True | `< 0.85` | 任意 | **True** | 调用（置信不足，图仍有增益） |
| True | `>= 0.85` | `< 8` | **True** | 调用（召回不足，图仍有增益） |
| True | `>= 0.85` | `>= 8` | **False** | **跳过**（高置信 + 召回充足），`metrics.incr("rag.graph.skipped_by_router")` |

### 3.2 `_wiki_should_nav(ilike_terms)`（`retrieve/__init__.py:58-68`）

判定：`selective off → True`；`selective on → len(ilike_terms) < 3`。

| `wiki_nav_selective` | `len(ilike_terms)` | 返回值 | 动作 |
|---|---|---|---|
| False（默认） | 任意 | **True** | 执行 wiki 导航扩词（与未引入路由一致） |
| True | `< 3` | **True** | 执行（词元稀疏，扩词仍有增益） |
| True | `>= 3` | **False** | **跳过**（词元已丰富），`metrics.incr("rag.wiki.nav.skipped_by_router")` |

> 注意：wiki 路由用 `ilike_terms`（前置信号），而图路由用 `retrieved[0].final_score` + `len(retrieved)`（主召回结果），二者信号来源不同，是因为 wiki 导航发生在主召回之前、图召回发生在主召回之后（`检索链路全景.md` §0 / §9 / §10）。

## 4. 三条不变量（设计纪律）

1. **默认关 = 行为零变化**：两个开关默认 `False` 时，两个纯函数恒 `True`，与未引入路由逐字节相同。`settings.py:156` / `:182`、docstring `retrieve/__init__.py:49` / `:62`。
2. **fail-open（路由只决定 CALL，绝不改分）**：路由只决定「是否调用 `recall_by_graph` / 是否执行 wiki 导航」，绝不改变任何片的分数或排序。即便路由判断失误，最坏只是「多跑一次图 / 多扩一次词」，不会劣化已召回结果（`recall.py` 自身也是 fail-open，见 [`GraphRAG检索召回.md`](./GraphRAG检索召回.md) §3.4）。
3. **可观测计数器**：跳过时各自打点 `rag.graph.skipped_by_router`（`retrieve/__init__.py:578`）/ `rag.wiki.nav.skipped_by_router`（`:291`），供标定期量化「跳过率」与「省下的延迟」。

## 5. 标定计划（CALIBRATION — 待执行）

### 5.1 方法

- 工具：`scripts/run_eval.py`（217 条用例，`AGENT_CONTEXT.md` §9 指令 3）。
- 两个跑批：**baseline**（两个 selective 开关关）= 当前生产态；**selective-on**（两个开关开）= 路由生效态。
- 用例集指纹（case_fingerprint）不一致时基线对比 MUST 跳过（不可比），见 `EvalRun` 模型约定（`models/entities.py:676-699`）。

### 5.2 门禁（MUST NOT 回退）

| 指标 | 门禁 | 含义 |
|---|---|---|
| `REFUSAL`（拒答率） | `>= 0.90` | 该拒的答得上拒 |
| `MISS`（漏答率） | `<= 0.10` | 能答的不漏 |
| `HIT`（命中率） | `>= 0.80` | 命中质量达标 |

baseline 与 selective-on 的这三项**均不得回退**（diff 不劣化）才允许常开路由。

### 5.3 报告项

- `skipped_by_router` 跳过率：图路 / wiki 路各报，量化「实际省了多少次调用」。
- 延迟节省：图路省一次 DB 往返（p95 目标 ≤ 80ms，`settings.py:164`）、wiki 路省一次 50ms SELECT（`settings.py:203`）。

### 5.4 回滚规则

- 若 **wiki 方向回归**（扩词跳过导致命中下降）：下调 `WIKI_NAV_SELECTIVE_MIN_TERMS`（如 3 → 2，仍受 `self_check` 上界 `ILIKE_MAX_TERMS=3` 约束），或把 wiki 导航**移到主召回之后**执行（改信号来源），再重跑 A/B。
- 若 **图方向回归**：下调 `GRAPH_SKIP_SCORE`（仍须 `> 0.5`）或提高 `GRAPH_SKIP_MIN_CHUNKS`，再重跑 A/B。
- 任一不可接受 → 两个开关维持默认关，逐字节等价基线不受影响（默认关即安全态）。
