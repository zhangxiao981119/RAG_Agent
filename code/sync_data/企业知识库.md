# 企业管理制度汇编

## 1. 报销流程

员工报销需遵循以下流程：
1. 填写报销单，附上发票原件
2. 部门主管审批（金额 < 5000 元）
3. 财务部审核（金额 >= 5000 元需总监审批）
4. 出纳付款

报销需要附的材料：发票原件、费用明细表、出差审批单（如适用）。
差旅费报销需要提供：机票/火车票、酒店发票、出差审批单。

财务审批流程分为三层：部门主管（<5000）、财务总监（<50000）、CEO（>=50000）。

## 2. 考勤制度

公司实行标准工时制，每周工作 5 天，每天 8 小时。
上班时间：9:00-12:00，13:30-18:00。
迟到超过 30 分钟视为旷工半天。
月累计迟到 3 次以上扣绩效分。

公司法定节假日按国家规定执行，如遇调休另行通知。

## 3. 新员工入职流程

新员工入职流程：
1. HR 发送 offer letter
2. 员工提交材料（身份证、学历证明、离职证明、体检报告）
3. 签订劳动合同和员工手册
4. 开通邮箱和系统账号
5. 部门报到和导师分配

新员工在入职后 7 天内需要签员工手册确认书。

## 4. 公司组织架构

公司组织架构：
- 总部
  - 技术中心（后端组、前端组、测试组、运维组）
  - 财务部
  - 人力资源部（薪酬组、招聘组）
  - 市场部
  - 行政部

## 5. 代码规范

代码规范对语言选择的要求：
- 后端服务使用 Python 3.11+
- 前端使用 TypeScript + React 18
- 数据库使用 PostgreSQL 15+

代码提交规范：使用 Conventional Commits 格式（feat/fix/docs/refactor/chore），每个 commit 只做一件事。

API 设计规范要求：
- RESTful 风格，资源名用复数
- 统一前缀 /api/
- 分页参数用 page + page_size
- 错误返回统一 JSON 格式 {code, message, detail}

## 6. 绩效考核

绩效考核采用 OKR + 360 度评估体系。
绩效考核结果分四档：S（优秀）、A（良好）、B（合格）、C（待改进）。
每季度评估一次，年终综合评定。

## 7. 薪酬结构

公司薪酬结构：
- 基本工资（60%）
- 绩效奖金（25%）
- 福利补贴（15%）

福利补贴包括：餐补、交通补贴、通讯补贴、节日福利。

## 8. 安全操作规程

安全操作规程包含以下内容：
- 服务器访问需通过堡垒机
- 数据库变更需走审批流程
- 生产环境部署需双审
- 敏感数据脱敏后才能用于测试
- 定期安全审计（每季度）

## 9. 故障处理流程

故障处理的标准流程：
1. 发现故障后 5 分钟内通知值班群
2. P0 级故障 15 分钟内启动应急响应
3. 恢复后 24 小时内提交故障报告
4. 每周复盘故障

## 10. 劳动合同

劳动合同模板包含以下条款：
- 合同期限（固定期限/无固定期限）
- 工作内容和工作地点
- 工作时间和休息休假
- 劳动报酬
- 社会保险和福利
- 劳动保护和条件
- 合同变更/解除/终止条件
- 违约责任

## 11. 年度预算报告

年度预算报告核心数据：
- 总预算：5000 万元
- 技术投入：1500 万元（30%）
- 人力成本：2500 万元（50%）
- 运营费用：800 万元（16%）
- 储备资金：200 万元（4%）
